# Pop Punk'd

A fun guessing game where players try to identify pop-punk bands based on progressively revealing hints.

## About the Game

Pop Punk'd challenges players to guess a pop-punk band in 6 tries or less. With each incorrect guess, a new hint is revealed, making it progressively easier to identify the band. The game features:

- A collection of popular pop-punk bands
- Hints including first letter, year formed, albums, songs, lyrics, and blurred images
- Sleek, pop-punk inspired UI with animations and interactive elements
- Mobile-friendly design

## Technologies Used

- React
- Redux for state management
- Tailwind CSS for styling
- Custom animations and transitions

## How to Play

1. Make your first guess at the pop-punk band
2. If incorrect, a hint will be revealed
3. Continue guessing (up to 6 tries)
4. Hints get progressively more revealing
5. Try to guess the band before all hints are revealed!

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
   ```
   git clone https://github.com/yourusername/pop-punkd.git
   ```

2. Install dependencies
   ```
   npm install
   ```

3. Start the development server
   ```
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser
